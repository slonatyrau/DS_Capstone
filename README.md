# Анализ эффективности торговых стратегий для Verified Investing (2012-2026)

Интерактивный дашборд, ML-прогнозирование и статистическое исследование влияния секторов рынка и отдельных тикеров на прибыльность торговых операций на основе исторических данных аналитической платформы Verified Investing.

## 🚀 Основной функционал проекта:
* **Интерактивный дашборд (Streamlit):** Визуализация матрицы торговых стратегий, расчет метрик надежности (winrate) и секторной эффективности в реальном времени.
* **Статистический анализ (ANOVA):** В ходе исследования было математически доказано, что выбор сектора рынка критически и статистически значимо влияет на общую доходность торговой стратегии.
* **Машинное обучение (ML Predictor):** Построение и сравнение моделей классификации для предсказания успешности сделок.
* **Автоматизированный пайплайн данных:** Полный цикл обработки данных от сырого датасета до обогащения категориями экономики.

## 🛠 Стек технологий:
* **Язык программирования:** Python (Pandas, NumPy)
* **Визуализация:** Streamlit, Plotly, Matplotlib
* **Статистика:** SciPy (ANOVA-тесты)
* **Machine Learning:** Scikit-learn (Decision Tree, Random Forest), XGBoost
* **Интеграции:** Yahoo Finance API, Gemini API (LLM-парсинг секторов)

## 📁 Структура репозитория и пайплайн:
* `app.py` — основной код веб-интерфейса интерактивного дашборда.
* `Data_Prep02.ipynb` — **Шаг 1:** Первичная очистка данных, исправление форматов дат, обработка пропусков и удаление лишних символов.
* `Data_Prep03.ipynb` — **Шаг 2:** Автоматическое обогащение данных. Добавление категорий (секторов экономики) через комбинацию Yahoo Finance API и запросов к LLM Gemini.
* `Data_Analyze04.ipynb` — **Шаг 3:** Разведочный анализ данных (EDA), визуализация распределений доходности и проверка статистических гипотез (ANOVA).
* `Data_ML05.ipynb` — **Шаг 4:** Обучение моделей машинного обучения, подбор гиперпараметров и сравнительный анализ метрик (Random Forest vs XGBoost).
* `raw_trades.csv` — исходный массив сырых данных по сделкам, выгруженный с веб-сайта.
* `trades_structured2.csv` — финальный структурированный датасет, готовый к анализу и обучению моделей.
